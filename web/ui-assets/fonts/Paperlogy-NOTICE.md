# Paperlogy font notice

This project bundles Paperlogy WOFF2 files for the game's Korean UI.

- Font family: `Paperlogy`
- Source: https://github.com/fonts-archive/Paperlogy
- Original distribution: https://freesentation.blog/paperlogyfont
- Files used: Paperlogy-4Regular through Paperlogy-9Black

The distribution describes Paperlogy as a free commercial font under the
SIL Open Font License (OFL): it may be used, modified, and redistributed,
except for selling the font by itself or changing the font license. Confirm
the current license terms with the original distribution before a release.
