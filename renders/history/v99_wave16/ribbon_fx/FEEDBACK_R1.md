## 어떻게 알았나 (런타임 실측)

`?dev` 로 띄우고 유니폼을 직접 읽었다:
```
uStyle = 1          ← 봉인칼. 셰이더 맨 위 style-1 분기로 빠져서
uMode  = 1            uMode 1(B 리본) 코드에 **도달조차 안 한다**
uRibbonV2 = 1       ← 켜져 있다. strands 3. 네 코드는 멀쩡하다
uPal[6] = (1,1,1)   ← plain 팔레트. water 가 아니다
```
근거: `main.js` 의 `let swordIdx = 0;` → `SWORDS[0] = { key:'nokseun', el:'plain' }`
→ `setElement('plain')` → `ELEMENTS.plain.style = 1`.

## 그 분기가 화면에 무엇을 칠하나 (ACES 통과 후)

```glsl
if (uStyle > 0.5 && uStyle < 1.5) {
  if (kind > 0.5) discard;
  float hw = 0.5 * (0.30 + 0.70 * (1.0 - u));
  float q  = abs(v - 0.5) / hw;
  vec3 cc = q < 0.26 ? uPal[6] : (q < 0.50 ? uPal[5] : (q < 0.68 ? uPal[3] : uPal[0]));
  gl_FragColor = vec4(cc, vA * (1.0 - 0.35 * u) * ea);
  return;
}
```
| 자리 | 폭 | 팔레트 | **화면 sRGB** | 화면 V | 화면 채도 |
|---|---|---|---|---|---|
| `q < 0.26` 심 | 26% | `#FFFFFF` | `#D1D1D1` | **209** | **0.00** |
| `q < 0.50` | 24% | `#D8F4FF` | `#C9CED0` | **208** | **0.03** |
| `q < 0.68` | 18% | `#7FD4F5` | `#AEC7CE` | **206** | **0.15** |
| 나머지 | 32% | `#0A1220` | `#192D45` | 69 | 0.63 |

**단면의 68% 가 화면 V 206~209 · 채도 0.00~0.15 다.** 게다가 `ELEMENTS.plain.tGain = 1.28`
로 폭까지 한 단 넓다. 이게 두 codex 세션과 오너가 본 "깃발"의 실물이다.

## 흰 심이 왜 안 나오는지 — 내가 잰 것 (진단은 네 몫)

머리 구간 조건은 `bt > 1.0 - whiteW` = `bt > 0.88` 이다.
그런데 그 바로 아래 줄이 바깥 먹을 덮어쓴다:
```
float outerOw = ow * 0.72;                     // ow = clamp(3.6/halfPx, 0.10, 0.30)
if (bt >= 0.5 && dN < outerOw) c = B_K;
```
실측 `halfPx` 최대 **16.8** (`vHalf` 0.2385m × `uPxPerM` 70.4) → `ow = 0.214`,
`outerOw = 0.154`. `bt = 0.94` 인 화소의 `dN = 1 - 2×|0.94-0.5| = 0.12 < 0.154`
→ **흰 심 자리가 통째로 바깥 먹에 먹힌다.** 얇은 마디에서는 더 심하다.
