# 참격 포말 마루 라운드 2 구현 보고

## A. 무엇을 왜 바꿨나

R1 원화는 격리 컷에서 이미 맞았으므로 다시 그리지 않고 합성 경계와 운반만 갈았다. 굽기에서 런타임 UV `v=0.20` 아래의 밝은 하부 물결을 제거하고 `v=0.04~0.20`의 기존 먹 화소만 경계로 남겼으며, 런타임은 main.js B 리본과 같은 플레이어 가슴 기준 방사축 및 `tipK=1.03`을 받아 그 밝은 시작선을 리본 외곽보다 0.08m(기준 카메라 약 4px) 밖에 정박시킨다. 길이축도 방사축에 직교시켜 갈고리가 리본 진행 접선에 눕고 길이 오프셋이 포말을 다시 안쪽으로 밀 수 없게 했다. 리본 샘플의 바깥 비행은 연속 칼끝으로 `속도×0.16`, `0.40^dt` 감쇠를 재현해 포말도 같이 운반한다. 부수 결함은 생성 간격 `0.28→0.22m`로 사슬을 잇고, f1 제거 뒤 원판으로 드러난 팝 f0를 3:1 짧은 붓획으로 바꿔 닫았다. NormalBlending, 선형 1.0 이하 팔레트, 24fps 게임시계, 부정형 discard, 상시 visible, 4/5/6칸 수명과 `FOAM_CREST_V2` 롤백은 유지했다.

- `tools/bake_foam_crest.py` — R2 합성 절단과 밝은/먹 최저 UV 자체 검증.
- `web/tex/foam_crest_sheet.png` — 같은 16종 원화를 R2 절단 계약으로 재굽기.
- `incoming/codex_foam/README.md` — R2 절단 규격과 배치 계약 추가.

원화 두 PNG와 금지 파일은 바꾸지 않았다. 공유 작업트리의 `web/main.js` 변경은 프로듀서가 이미 꽂은 R1 통로이며 이 작업에서는 편집하지 않았다.

## C. main.js 통로 변경

**필요하다.** 정확한 리본 바깥축을 재현하려면 현재 한 줄을 아래로 교체한다.

```js
feel.trailFoamSample(a, b, attacking ? wake : 0, root.position, charH);
```

정확한 시그니처:

```js
feel.trailFoamSample(a, b, wake, rootPos, charH): boolean
// a, b, rootPos: THREE.Vector3 (함수 안에서 즉시 복사)
// wake: number 0..1
// charH: number, main.js가 B 리본 가슴 기준점에 쓰는 캐릭터 높이
```

옛 3인자 호출도 오류 없이 칼날 방향 폴백으로 돈다. 다만 `rootPos,charH`가 있어야 main.js의 `플레이어 가슴 → 칼끝` 방사 방향 및 `tipK=1.03`과 정확히 같은 자로 밝은 포말을 리본 밖에 놓는다. `FX_TABLE.b.sprayK = 0.0`은 그대로 둔다.

## D. 롤백

`web/feel.js`의 아래 한 줄만 바꾼다.

```js
const FOAM_CREST_V2 = 0;
```

새 포말층이 꺼지고 팝은 기존 두 장 경로로 돌아간다. main.js의 5인자 호출은 남아 있어도 함수가 즉시 `false`를 반환하므로 안전하다. 자유 물방울까지 완전한 옛 화면으로 되돌릴 때만 프로듀서가 별도로 `FX_TABLE.b.sprayK = 1.0`을 복구한다.

## E. 확신 못 하는 것

- 이 응답 환경에는 제어 가능한 브라우저 백엔드가 없어 실제 Z/X/C 합성 재캡처, 점유, 950프레임, fps A/B를 다시 재지 못했다. `node --check`, 재굽기 자체 검사, 알파/밝기/UV 계약, `git diff --check`까지는 통과했다.
- R1 점유 정점 X 5.03%·C 3.76%에서 밝은 면을 밖으로 드러내는 변화와 간격 0.22m가 함께 들어가므로 최종 점유가 3~7% 안에 남는지는 하네스 재측정이 필요하다. 시트 live 면은 절단 뒤 셀당 8~36%라 증가분을 일부 상쇄한다.
- main.js는 drift 벡터를 프레임마다 `_advAxis`로 회전하지만 현 통로에는 그 축이 없다. R2는 핵심 병진 계수 `속도×0.16`과 감쇠 `0.40^dt`까지만 맞췄다. 짧은 4/5/6칸 수명에서는 차이가 작을 것으로 보지만 C의 가장 휘어진 칸은 실측 확인이 필요하다.

## 검증 수치

- 시트: 2048×1024, 4×4, 셀 512×256.
- 알파: `[0,255]`; 밝기: `[31,117,179,242]`.
- 16칸 공통 밝은 화소 최저 UV: `0.199219`; 먹 최저 UV: `0.046875`.
- 런타임 밝은 시작선: B 리본 `tipR×1.03` 바깥 `0.080m`.
- 최대 반높이 `0.28m`와 선형 샘플 가장자리까지 계산해도 밝은 화소 외곽 여유는
  약 `0.0796m`다. 원래 먹 화소만 최대 약 `0.0058m` 리본 경계에 걸친다.
- 재굽기 SHA-256 일치: `372e00d9a171f99f78d1b92314355e6b8049aa50d8776f0a718d294b08b22be1`.
- 포말 수명/소멸: 기존 4/5/6칸, 최대 0.25초 유지.
