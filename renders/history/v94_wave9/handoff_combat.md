## 1. 다른 파일에 부탁하는 것

### A. `enemy.js` (9A-3 또는 다음 소유자)

**A-1. 대시 무적 창구 `setIframe(sec)` — 제일 급하다**
main.js 는 이미 `if (typeof enemies.setIframe === 'function') enemies.setIframe(0.20)` 로
**붙는 즉시 먹게** 불러 두었다. 지금은 그 함수가 없어서 조용히 건너뛴다.

- 필요한 이유: 잡몹 타격은 enemy.js 안에서 `damagePlayer` 를 **직접** 부른다(1913행).
  main.js 가 넘긴 콜백을 안 지나므로 바깥에서 막을 방법이 없다.
  보스 피해는 main.js 콜백을 지나므로 **이미 막고 있다**(대시 중 보스 피해 0).
- 구현은 한 줄이면 된다: `setIframe(s) { iframe = Math.max(iframe, s); return iframe; }`
- 이게 붙기 전까지 대시는 **자리 이동으로만** 피한다(보스 장판은 명중 순간 좌표를
  다시 재므로 그것만으로 100% 회피된다 — 3장 실측 참고).

**A-2. `SWING_GAP` 0.22 → 0.12 검토**
`SWING_GAP` 안쪽에서 다시 켜진 hot 은 **같은 스윙**으로 묶여 번호가 안 올라간다
(= 같은 요괴를 다시 못 벤다). 9차에서 연타 반응을 올리자 스윙 간격이 0.14~0.17초까지
줄어서, 그대로 두면 **보이고 들리는데 안 들어가는 스윙**이 생긴다.
main.js 는 그걸 막으려고 연타 바닥 `ATK_MIN_GAP = 0.24` 를 깔아 뒀다(0.22 + 여유).
SWING_GAP 을 내리면 main.js 의 바닥도 같이 내린다 — 그만큼 연타가 빨라진다.

**A-3. `snapFacing` 의 `SNAP_DUR`(0.09s)**
스냅이 몸을 0.09초에 걸쳐 돌리는데 3연타 1타 타격은 0.069초에 들어간다.
= **몸이 아직 등을 보인 프레임에 판정이 돈다.** 이게 심사의 "등 뒤도 베인다"의 진범이었다
(실측: 정확히 180° 뒤 요괴가 8회 중 7회 베였다 — `combat/backhit.json`).
main.js 쪽에서 두 겹으로 막았다(아래 3장). enemy.js 쪽에서 더 좋게 하려면
`SNAP_DUR` 을 0.05 이하로 줄이거나(몸이 먼저 다 돌게), 스냅 중에는 hot 을 늦추면 된다.

**A-4. 프로브가 복사해 쓰는 상수**
`window.__reach` 프로브가 `HOT_ON 0.42 / HOT_OFF 0.16` 을 main.js 안에 복사해 갖고 있다.
enemy.js 에서 이 값을 바꾸면 **프로브도 같이 고쳐야** 리치 표가 거짓말이 안 된다.

### B. `ui.js` / `index.html` (9A-2)

**B-1. 조작 안내에 대시 추가 — 지금 안내가 거짓말이다**
확정 배치: **이동키를 누른 채 Space = 대시(회피)** / **가만히 Space = 점프**.
지금 안내는 `Space 점프` 한 줄뿐이다. 이렇게 갈라 적어 달라:

```
Space      점프
이동+Space 회피 (3.5m · 쿨 1.2초)
```

점프와 충돌하지 않는 이유: 두 동작의 조건이 **배타적**이다(방향 입력 유무).
제자리에서 회피할 이유가 없고, 이 게임에서 달리며 점프할 이유도 없다.
새 키를 안 쓴 이유: 방향키+Shift+Z/X/C 로 왼손이 이미 꽉 차 있다.

**B-2. 회피 칩은 main.js 가 `#uiSkills` 에 붙인다**
`<div class="sk" data-k="Dash"><i class="cd"></i>…` 구조로, ui.js 의 `.sk` / `.cd` CSS 를
그대로 탄다(쿨다운 라디얼도 같은 방식으로 그린다 — handoff_ui A-5 반영 완료).
**ui.js 가 칩 구조나 클래스 이름을 바꾸면 여기도 같이 봐야 한다.**
`#uiSkills` 가 없으면 조용히 포기하도록 되어 있어 깨지지는 않는다.

**B-3. 거부 흔들림 클래스**
못 쓰는 입력에 main.js 가 칩에 `.deny` 를 0.22초 얹는다(키프레임은 main.js 가 자기
`<style id="mainFxStyle">` 에 넣는다). `.sk` 에 `overflow:hidden` 이 걸려 있어 흔들림이
잘리지 않는지만 봐 달라(지금은 translateX 4px 라 안 잘린다).

**B-4. 피격 방향 비네트**
main.js 가 `#hurtDir`(z-index 8, pointer-events none)를 만든다. UI 판이 그보다 위에
있어야 하면 z-index 를 조정해 달라.

### C. `boss.js` (9A-3)

**C-1. 장판 반경을 줄이는 중이라고 들었다.** 대시는 3.5m 를 0.18초에 간다.
지금(내려찍기 반경 4.0m · 예고 1.2초) 교전 거리 2.8m 에서 한 번이면 6.3m 로 벗어난다.
반경을 줄여도 **예고 시간을 0.5초 밑으로 내리지만 마라** — 대시 입력 반응(0.15~0.25초)
+ 대시 0.18초라 0.5초 아래면 반응 자체가 불가능해진다.

## 3. `?x=` 자체 리로드 규명 (심사 손맛 10위)

**코드에는 리로드가 한 줄도 없다.** `web/` 전체(js·html)에서 `location.reload` ·
`location.href=` · `history.pushState` · `?x=` 가 **0건**이다(grep 로 확인).
사망·R·클리어는 원래부터 인플레이스였다(`toSpawn` + `resetKills` + `boss.restart`).

그럼 심사에서 본 "?x=1, ?x=5 로 URL 이 바뀌며 3회 리로드"는 무엇인가:
**검증 도구가 캐시를 우회하려고 붙인 쿼리다.** 이 레포는 `index.html` 이 모듈을
`import('./main.js' + location.search)` 로 부르고 모든 하위 모듈·glb 에 쿼리를 물려
주는 구조라(LOG.md '웹 함정 7'), 캐시를 깨려면 URL 에 아무 쿼리나 붙여 다시
navigate 하는 게 관행이다. 그 흔적이 `?x=N` 이다. 게임이 스스로 한 일이 아니다.

**그래도 이번 파도에서 한 것**: 되돌리는 창구가 세 군데로 흩어져 있어 무엇이 리셋되는지
아무도 몰랐다. `resetRun()` 한 함수로 모았다(자리·체력·요괴 전원 재배치·보스·증표·
소요 시간·공격/대시/점프/콤보/궤적/선입력/예고음). R 키 두 경로가 전부 여기를 지난다.

**실측**: 부팅 1회 이후 사망·R·클리어까지 `framenavigated` **0회**
(`combat/after_metrics.json` · `combat/run_noreload.json` 의 `navs`).

## 4. 함정 (다음 사람이 또 밟을 것들)

- **`enemy.reset()` 은 안쪽에서 `onRespawn()` 을 부르고, main.js 의 `onRespawn` 은
  플레이어를 스폰으로 순간이동시킨다.** 검증 스크립트에서 "체력만 채우고 그 자리에
  두려고" 부르면 자리가 통째로 날아간다(보스 실측이 20시행 내내 0건이 나온 원인이었다).
  되돌린 **뒤에** `__put` 할 것.
- **`?dev` 로 타이밍을 재지 마라.** `?dev` 는 루프가 `setTimeout(16)` 이라 벽시계 대비
  게임시계가 느리게 흐른다. 같은 항목이 dev 에서 2.4초, 비-dev 에서 1.2초로 나왔다.
  타이밍은 비-dev 에서, 또는 **게임시간(`__atk().since`)** 으로 재라.
- **Playwright `waitForFunction` 의 기본 rAF 폴링은 메인 스레드 블록 중 굶는다.**
  부팅(파싱이 1~8초 메인 스레드를 문다)을 기다릴 땐 `{polling: 400}` 을 줘야 한다.
- **부팅 게이트에 백스톱을 빼먹지 마라.** "프레임이 매끄러워지면 연다"만 두면 느린
  기계에서 영영 안 열려 로딩 화면에 갇힌다(3초 백스톱을 넣었다).
- **`window.__probe` 는 이미 main.js 가 쓰는 이름이다.** 검증 스크립트가 같은 이름으로
  덮으면 조용히 사라진다(한 번 밟았다). 스크래치패드 파일명도 에이전트끼리 공유되니
  접두어를 붙일 것(여기서는 `w9b1_`).
- **대시가 `Run` 클립의 `timeScale` 을 잠시 덮어쓴다.** 원본을 적어 뒀다가 되돌린다
  (`dashTsSaved`). 1 로 되돌리면 캐릭터별 걷기/달리기 재생속도(CHAR_CFG)가 통째로 깨진다.
- **`moving` 조건에 대시를 빼먹으면** 애니 상태 기계가 매 프레임 `play('Idle')` 로 덮어서
  대시 동작이 화면에 안 나온다(한 번 밟았다).
