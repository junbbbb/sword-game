# 19차 소리 실측 (2026-08-18)

두 건이다. **①베는 소리를 녹음으로 교체 ②휘두름이 채찍으로 들리던 것 수정.**
전부 `web/sfx.js` 한 파일 안에서 끝났다(main.js·enemy.js 는 한 줄도 안 고쳤다 —
`sfx.hit()` 부르는 자리가 이미 "몬스터를 벤 순간" 두 곳뿐이라 손댈 이유가 없었다).

측정 도구는 게임에 원래 있던 `sfx.level()`(master 뒤 analyser)이다. 새로 만들지 않았다.

---

## 0. 측정할 때 걸린 함정 — 앰비언스가 바닥을 깔고 있다

바람·풀벌레가 항상 돌기 때문에 **rms 측정에 바닥값이 섞인다**(floor rms 0.00448).
그래서 아래 rms 는 전부 **전력으로 바닥을 뺀 값**이다: `net = sqrt(측정² − 바닥²)`.

★더 큰 함정: `level().bands.bug` 는 4400~6600Hz 인데 **풀벌레가 정확히 그 대역**
(4700 · 6250Hz)에 산다. 처음에 이 대역으로 "소리가 끝에서 치솟나"를 재려다
**풀벌레를 재고 있었다.** 그 측정은 버렸다. 대역으로 뭘 판정하려면 앰비언스와
겹치는지부터 볼 것.

## 1. 베는 소리 (SFX_HIT_V19)

### 음원
freesound 796647 "Skinning Animal 1" / Frostnox / **CC BY 4.0**(상업 가능, 표기 의무).
출처·가공 내역·표기 문구는 `web/sfx/NOTICE.md`.

### 원본을 그대로 못 쓴 이유 (파형 실측)
| 구간 | 내용 |
|---|---|
| 0~130ms | 사실상 무음(-45~-57dB). 그대로 틀면 **칼이 닿고 140ms 뒤에** 소리가 난다 |
| 132ms | 닿는 톡(peak 0.051) |
| 142ms | 본체가 갈라지는 순간(peak 0.157) |
| ~205ms | 바닥으로 감쇠 |
| 225ms | **20ms 떨어져 뚝 튀는 잔소리** — 넣으면 두 번 벤 것처럼 들린다 |

주파수: 원본 에너지의 **38%가 300Hz 아래**(마이크 럼블). 이 게임은 명중 순간
90~120Hz 로 저역 퍽을 따로 치므로 그대로 두면 두 저역이 같은 자리에서 부딪힌다.

→ **0.130~0.207초만 잘라 77ms**, 170Hz 아래·11kHz 위를 깎고 피크 -1dBFS 로 정규화.
→ 7.5KB **wav**. ogg 는 사파리가 못 읽고, mp3 는 앞에 무음 패딩이 붙는다(77ms 짜리
   타격음에 치명적). 이 길이에선 무압축이 원본 ogg(15KB)보다도 작다.

### 음량 맞추기 (6~8회 평균, 바닥 보정)
| | 옛 합성 | 새 녹음 | 차이 |
|---|---|---|---|
| 명중 rms | 0.0262 | 0.0279 | **+0.55dB** |
| 명중 peak | 0.0843 | 0.1030 | +1.74dB |
| 처치 rms | 0.0625 | 0.0645 | **+0.3dB** |

처음 잡은 0.24 는 rms +1.5dB / peak +3.9dB 로 명중만 커져서 **0.18 로 내렸다.**
rms(체감 음량)가 같으면 맞은 것이고, peak 이 조금 높은 건 녹음의 결이 합성 노이즈보다
날카로워서다 — 그게 목적이다.

처치는 겹을 하나 더 얹었는데 rms +0.3dB = 사실상 동일하다(컴프레서가 먹어 줬다).

### 처치음 판단
**명중만 실물로 바꾸면 더 중요한 순간이 더 싸구려로 들린다.** 그래서 처치에도 같은
녹음을 얹되 **기존 7겹은 하나도 안 뺐다**(처치는 명중보다 굵어야 구분된다).
streak 반음을 재생속도에 넣어 연속 처치에 녹음도 같이 올라간다.

## 2. 휘두름: 채찍 -> 칼바람 (SFX_SWING_V19)

### 원인 (오너: "무슨 채찍 소리가 나냐")
음량 문제가 아니라 **모양 문제**였다. 옛 휘두름은 두 겹 다
**주파수가 처음부터 끝까지 위로만 올라갔다**(520 -> 2650Hz / 2200 -> 5200Hz).
그게 채찍 소리의 정의다 — 끝으로 갈수록 올라가다 터지는 상승 스윕.
게다가 봉투가 길이의 14% 에서 최대를 치고 꺼져서 **"부는 소리"가 아니라 "때리는
소리"의 몸**을 하고 있었다. 그래서 음량만 줄여도 채찍은 안 없어진다.

### 고친 것
- 주파수를 **호**로: `fc*0.55 -> fc(45%) -> fc*0.40` = 다가왔다 지나가는 도플러
- 봉투도 같은 45% 지점에서 정점(부풀었다 빠지는 바람). **두 정점을 같은 자리에** 맞춤
- Q 1.5 -> 0.8 (쨍한 결 -> 바람 결)
- 고역 겹을 **내려가게** 뒤집음(올라가면 그게 크랙이다) + 뒤로 12ms 밀어 본체에 숨김

실측 궤적(고역대 8회 평균, dB): 정점이 **길이의 43% 지점**에 서고 양쪽으로 대칭으로
빠진다 = 설계한 호가 그대로 나왔다.
```
-86.7 -88.1 -88.5 -88.6 -85.9 -76.0 [-71.9] -72.5 -77.1 -81.9 -87.6 -89.6 -90.6
                                      ^ 43%
```

### 음량 — 위계가 뒤집혀 있었다
| | 옛것 | 새것 | 차이 |
|---|---|---|---|
| 평타 휘두름 rms | 0.00817 | 0.00524 | **-3.6dB** |
| 큰 기술(X·C) rms | 0.03114 | 0.01839 | **-4.56dB** |

★**옛 큰 기술은 명중음보다 컸다**(rms 0.0314 vs 0.0289 = +0.8dB). 휘두름은 배경이고
타격이 주인공인데 반대였다. 지금은:
- 평타 휘두름 = 명중보다 **-14.7dB**
- 큰 기술 = 명중보다 **-3.8dB**

물결 반짝임(shimmer)과 저역은 **남겼다** — 그 두 겹이 "물의 호흡"의 표식이라
빼면 수면참·횡일섬이 그냥 센 평타로 들린다. 음량만 낮췄다.

## 3. 보이스 상한 — 이미 나 있던 사고를 발견했다

`MAX_VOICES` 는 2026-08-10 에 6->9 로 올리면서 "처치음 첫 겹이 잘려서" 라고 적어 놨는데,
**그때 세다 만 것이 있었다**: 처치(7겹) + 요괴 비명(3겹) = **10** 이라 9 를 넘긴다.
즉 그 수정 이후로도 계속 잘리고 있었다. 실전투에서 상한을 치는 게 실제로 관측된다
(cap 11 일 때 `maxVoices 11` = 상한에 붙음).

다시 셌다: 처치 8(19차에 한 겹 추가) + 비명 3 + 무리 전멸 3 = **14**.
임의의 여유가 아니라 한 프레임에 실제로 겹칠 수 있는 최대치다.
→ 14 로 올린 뒤 같은 전투에서 `maxVoices 12` = **상한에 안 붙는다**(여유 확인).

## 5. 처치음의 "둥"(북) 제거 (KILL_BOOM)

오너: "해치웠을때 둥 뭐 이런소리나는데 이거없애"

### 범인 특정 (저역 60~400Hz, 6회 평균, 50ms 칸)
| | 최대 | 바닥 위 지속 |
|---|---|---|
| 처치(옛) | **-38.1dB** | **350ms** |
| 명중 | -45.5dB | 150ms |

처치만 저역이 **7.4dB 크고 2.3배 길다.** 그 길게 우는 저역이 "둥"이다. 겹으로 짚으면:
- `tone(0.24초, sine 92 -> 40Hz)` — 사인이 아래로 미끄러지는 것 = **말 그대로 킥드럼**
- `lowTail(0.72초, 저역 콤 울림 fb 0.82)` — 그 북이 방에 남아 우는 꼬리
- `noise(0.20초, lowpass 150 -> 48)` — 서브가 두꺼워 북을 거든다

### 옛 저역 궤적 (북이 우는 모양)
```
-64.1 [-38.6 -38.1] -45.1 -56.1 -62.2 -63.5 -64.1 ...
       ^^ 두 칸을 -38 로 버틴 뒤 350ms 에 걸쳐 천천히 빠진다 = 울림
```

### 고친 뒤
```
-70.9 [-45.6] -48.3 -62.8 -70.2 (바닥)
       ^^ 한 칸 치고 200ms 안에 바닥. 울림 없음
```
저역 최대 **-38.1 -> -46.1dB** · 사인/꼬리 제거로 **100Hz 아래가 사실상 사라졌다**
(지금 제일 낮은 것은 85ms 짜리 lowpass 260->130 몸통 하나뿐이다).

### ★첫 판 실패: 북만 빼면 처치가 명중과 구분이 안 된다
북을 빼고 중역 보상을 0.20 으로 뒀더니 **처치 대 명중 = +0.33dB**(옛 +7.0dB).
굵기의 출처가 통째로 저역이었기 때문이다. **저역에서 중역으로 옮기는 작업이라
옮긴 만큼 채워야 한다** — 젖은 중역을 두 겹(1000->420 · 620->340)으로 늘리고
몸통·낮은 종을 올려서 **+3.78dB** 로 앉혔다. 사인은 안 쓴다(사인이 곧 북이다).

| | 옛것 | 첫 판 | 최종 |
|---|---|---|---|
| 처치 대 명중 | +7.0dB | +0.33dB(얇음) | **+3.78dB** |
| 저역 최대 | -38.1dB | -53.4dB | -46.1dB |
| 저역 지속 | 350ms | 50ms | 200ms |

최종의 저역은 220~340Hz 대(살 가르는 몸통)이지 40~120Hz 북통이 아니다.

### 검증
실전투 Z26+X+C: 처치 5 · 베는 소리 20회 · 보이스 168 · maxVoices **14/14**
(처치8+비명3+전멸3 의 설계 최악값에 정확히 맞아 **잘림 없음**) ·
