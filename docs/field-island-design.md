# 초원 재설계 — "하늘에 뜬 섬" (23차, 2026-08-24)

오너 지시: "맵도 짜임새 있게 설계해봐. 그냥 보기 좋게 말고. 오디세이 영화 보니까
각 섬에서 너무 재밌더라. 그런 데서 영감을 얻어도 돼."

## 0. 왜 오디세이의 섬인가 — 그리고 왜 이 게임에 맞는가

오디세이의 각 섬이 재미있는 이유는 셋이다.
1. 섬마다 **상륙 → 탐색 → 시련 → 탈출**의 완결된 아크가 있다
2. 섬마다 **하나의 뚜렷한 규칙**이 있다(키클롭스=갇힘, 세이렌=유혹). 지형이 곧 그 규칙의 무대다
3. 다음 섬은 **전혀 다른 경험**임을 약속한다

이 게임의 뼈대와 정확히 맞물린다:
- 외관 컨셉 1순위가 SAO 다. 아인크라드 = **하늘에 뜬 탑, 층마다 다른 세계**. "탑의 층 = 떠 있는 섬" 은 SAO 문법 그대로다
- 20차 아이템이 이미 미케네 고증(청동 소가죽 잉곳·황금 탈란톤 = 오디세우스 시대)이다. 세계관이 먼저 와 있었다
- 게임 제목이 "탑의 생존자 / TOWER CHRONICLE" — 층 서사에 "표류자가 섬에 떠밀려 온다" 아크를 얹으면 층마다 완결이 생긴다

**이번 재설계의 정의: 초원(level1)을 "1층 = 첫 번째 섬" 으로. 상륙 → 갈림길 →
두 개의 다른 놀이 구역 → 관문 → 보스** 의 아크를 지형으로 만든다.

## 1. 현 상태 진단 (재설계의 근거)

- 아래 절반이 거의 완전한 **좌우 대칭** — 대칭은 설계가 아니라 패턴으로 읽힌다. 갈림길에 선택의 이유가 없다
- 몹 10무리가 **균등 살포** — 조우 설계가 없다. 어디서 싸워도 같은 싸움이다
- 스폰 4곳이 네 모서리 — 멀티에서 친구와 흩어져 시작한다
- 북쪽 거대 덤불 사각형이 보스 아레나를 덮는다 — 클라이맥스 무대가 수풀 블록이다
- 페이싱 없음: 안전지대→긴장→해방의 리듬이 지형에 없다

## 2. 새 구조 (96×96 유지. X=동, Z=남. 북=화면 위)

```
        북(-Z)
┌─────────────────────────────────┐
│   [D 보스 성소]   절벽·안개 바다  │  넓은 원형 아레나. 무너진 산사 본당 터.
│      ▲ 관문 협곡(폭 4~6m)        │  좁아지는 길 = 긴장 → 아레나 = 해방
│ [B 수풀 언덕]      [C 폐허 마당] │  B=은신 놀이(덤불+매복)  C=개활 난전(기둥+무리)
│      ↖    [랜드마크 신목]    ↗   │  중앙 큰 신목(or 석탑) — 어디서든 방향 앵커
│         갈림길 마당              │  좌=멀지만 은신 우회 / 우=빠르지만 정면 난전
│      ▲ 오르막 흙길               │
│ [A 상륙 해안]  부서진 뗏목·잔교   │  스폰 전원 여기. 안전지대. 몹 없음 반경 12m
└─────────────────────────────────┘
        남(+Z) — 가장자리는 절벽 + 안개(하늘에 뜬 섬. 물은 만들지 않는다)
```

**대칭 금지.** B(서)와 C(동)는 크기·지형·놀이가 달라야 한다. B는 좁고 높낮이 있는
언덕+덤불(스텔스 시스템이 이미 있다 — 그게 빛나는 유일한 구역으로), C는 트인 마당에
Meshy 기둥·잔해가 엄폐물로 서는 난전 구역.

## 3. 조우 설계 (mobs[] 순서가 곧 마릿수다: 3+i%3 = 3,4,5 반복)

| # | 마릿수 | 자리 | 의도 |
|---|---|---|---|

바꾼 json 을 양쪽이 같이 받으면 문제없다(배포로 함께 나간다).

## 4. 스폰·출구·보스

- 스폰 4곳 전부 **해안 띠 안, 서로 8m 이내** — 멀티에서 친구와 같이 시작한다
- 보스 아레나는 성소(북중앙), 반경은 지금 arena 값 유지(보스 패턴 사거리 검증 범위)
- exits 는 지금 문법 유지(위치만 성소 뒤 절벽 쪽으로)

## 5. 지켜야 하는 것 (전부 기존 계약)

- 에셋은 **있는 것만**: props 5종(rock·crag·thicket·tree·bush) + Meshy 구조물 9종 + splatmap 3채널(풀/흙/판석). 새 메시가 꼭 필요하면 저폴리 절차 생성(나중에 Meshy 승격)
- 팔레트·조명 계약: 15차 처방전(docs/references/aaa-environment-craft.md) — 판석 덮임 55~75%, 채도는 바닥이 아니라 불·이끼·캐릭터에
- 배경=안개색 동일값, 개방감("첫 층" 오너 지시 2026-08-10)
- 콜라이더 문법: 축정렬 box + circle, 벽 금 만들지 말 것(17차 사고 — 상자 사이 0.22m 틈)
- grid 30×30 · cell 3.2 유지(nav.js·stealth.js 가 읽는다)
