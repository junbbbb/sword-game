## 1. 한눈에

**정체**: three.js 탑다운(쿼터뷰) 검 액션 **데모**. 스토리·진행 시스템은 최소이고, 목표는 "딱 봤을 때 캡처할 만큼 매력 있냐"다. 맵 두 장(던전 1층 = 기본 / 초원 = `?map=field`), 몬스터는 고블린 한 종, 보스는 초원에만 있다.

**배포**: <https://dist-phi-jet-62.vercel.app> (2026-08-19 확인: 200, 로컬 `dist/` 와 바이트 일치 = 20차 `fd4b2fe` 판이 떠 있다)

**저장소**: <https://github.com/junbbbb/sword-game> (비공개, `main` 브랜치)

### 로컬 실행

```bash
cd ~/Documents/gameproject/web && python3 -m http.server 8777 &
# http://localhost:8777  (관례 포트. Playwright 검증도 이 주소로)
```

`web/` 을 그대로 서빙하는 것이 전부다. 빌드 단계가 없다.

### 배포

```bash
python3 tools/build_deploy.py           # web/ -> dist/ 로 굽는다 (web/ 은 안 건드린다)
cd dist && vercel --prod --yes          # 141개 파일·70MB. 느리면 vercel deploy --prod --yes --archive=tgz
curl -s -o /dev/null -w '%{http_code}\n' https://dist-phi-jet-62.vercel.app
```

빌드가 하는 일(`tools/build_deploy.py` 헤더가 정본):

- `*.bak*` 백업과 안 쓰는 캐릭터 glb 를 뺀다(`KEEP_CHARS`. **`main.js` 의 `CHAR_LIST` 와 반드시 맞출 것** — kensa 를 빠뜨려 배포본 시작 캐릭터가 404 났던 사고가 있다)
- `dist/*.js` 의 `const GLB_VER = {};` **한 줄**을 md5 8자 표로 바꿔 glb URL 에 `?v=` 를 박는다. **이 줄의 생김새를 바꾸면 빌드가 못 찾는다.**
- `tools/deploy_config/vercel.json` 을 매번 새로 복사한다(캐시 헤더 정본이 git 안에 있다)

★**glb 캐시 사고(13차)**: `vercel.json` 이 glb 에 `max-age=31536000, immutable` 을 주는데 배포는 같은 URL 에 내용만 갈아끼운다. 한 번 다녀간 브라우저는 옛 glb 를 1년 동안 재검증 없이 쓴다(크롬 hard reload 로도 안 뚫린다). 실제로 배포본 시작 캐릭터가 알몸·맨손으로 떴다. `?v=` 버저닝이 그 답이고, **glb 를 읽는 새 경로를 추가하면 `THREE.DefaultLoadingManager.setURLModifier` 가 동적 import 보다 먼저 걸려 있어야 한다**(`web/main.js:48`).

★`dist/` 를 통째로 지우지 마라. `.vercel/project.json` 이 없으면 vercel 이 **새 프로젝트**를 만들어 안정 주소가 아닌 낯선 주소로 올라간다.

## 3. 작업 관례 — **이게 핵심이다**

### 위임과 병렬

- **코드 작업은 전부 서브에이전트에 위임한다.** 메인은 orchestration 만 한다(오너 지시, 2026-08-05).
- **파일 소유권을 분할해서 병렬로 돌린다.** 표로 적어 겹치지 않게 하고, 파일 간 요청은 handoff 문서로 넘긴다. 공개 API 시그니처는 병렬 중 변경 금지(추가만).
- 위임 스펙에는 **실측 원칙·해당 함정·검증 방법·한국어 주석**을 매번 명시한다.

### git

- **커밋 직전 `git pull --rebase`**, **파일을 명시해서 `add`**(`git add -A` 금지 — 오너가 IDE 로 동시 작업 중일 수 있다).
- 커밋 메시지는 **한국어 서사형**("무엇이 진짜 원인이었는지"를 한 문장으로). 예: `히트스톱은 있었다 — 그걸 지운 건 카메라였다`
- 메시지 끝에 빈 줄 하나 두고:
  ```
  Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>
  ```
- 배포 전 커밋이 관례다. `dist/` 와 배포는 **메인 오케스트레이터 소관**이다.

### 검증 문화

- **headed Playwright + 평시 URL**(`http://localhost:8777`). `?dev` 는 게임 시계가 `setTimeout` 이라 **타이밍 측정에 쓰면 안 된다**.
- **수치는 실측으로.** "그렇게 보인다"가 아니라 화소·월드 좌표·프레임 수를 센다. fps 는 A/B **왕복 교대**로(정순만 재면 드리프트한다), 950 표본이 관례 규모다.
- **A/B 대조 사본은 git HEAD 로 고정**해서 별도 포트에 띄운다(18차는 8791/8792/8793 을 썼다). 오너가 동시 작업 중이면 비교가 오염된다.
- 증거는 `renders/history/v99_waveN/<작업>/` 에 남긴다. **`renders/` 는 gitignore 라 로컬에만 있다**(빌드가 `dist/` 를 지우므로 거기 두면 날아간다).

### ★현 방침 (오너 지시, 2026-08-13 — 이게 위 검증 문화보다 우선한다)

> **"딱 봤을 때 캡처할 만큼 매력 있냐"가 최우선.** 홍보 우선이고 버그·사소한 에러는 나중이다. 4대 요소 = **모션 · 이펙트 · 몬스터 · 맵**.

정밀 QA(950 표본 전수 등)는 **게임이 깨지는 수준만** 확인하고, 아낀 시간을 보이는 맛에 쓴다. 20차 아이템 지시에도 같은 말이 붙었다("어짜피 보여주기식 demo니까 테스트 이런것도 최소한만해").

### 롤백

**모든 변경에 롤백 스위치 한 줄.** 새 판을 넣을 때 옛 판 코드를 지우지 않는다 — 지우면 스위치가 거짓말이 된다. 스위치는 **한 곳에서만 정의**하고(두 벌이면 반드시 어긋난다) 되돌린 화면이 옛 판과 같음을 md5·화소로 증명한다. 실물 인벤토리는 §4.

## 6. 오너 취향 · 기각 이력

같은 실수를 두 번 하지 않기 위한 목록이다.

- **최우선 기준은 매력이다.** "딱 봤을 때 캡처할 만큼 매력 있냐". 홍보 4요소 = 모션 · 이펙트 · 몬스터 · 맵. 정밀 QA 는 게임 깨지는 수준만.
- **외관 컨셉 = SAO + 나 혼자만 레벨업 + 게임 속 바바리안.** 깔끔한 애니 MMO 판타지. 기법은 **저폴리 + 핸드페인티드**(면에 그림을 그려 넣는 롤·WoW 방식. 오너가 직접 물어 확인했다).
- **브롤스타즈·포트나이트 방향은 기각됐다**(14차 → 15차에서 "저퀄·타일 덩어리 직육면체" 로 뒤집힘). 밝은 카툰 큰 블록으로 가지 마라.
- **귀멸 모사 이펙트도 결국 교체됐다.** 18차에 "귀멸의칼날처럼 말고 너가 그냥 이펙트를" 지시로 일섬이 나왔다. 다만 옛 판을 지우진 않는다.
- ★**카메라 기하 함정(16차 발견).** 게임 카메라 pitch 49.3° 에서는 월드 1m 위 = 화면 43px 위, 월드 1m **앞** = 화면 47px **위**라 "아래로"와 "앞으로"가 상쇄된다. **순수 시상면 세로베기는 원리적으로 안 읽힌다.** 베기 3종이 월드 수치로 세 번 통과하고 세 번 다 기각당한 이유가 이것이다. **모든 모션·자세 판정은 화면 기준**(`screen_px()`·8방향 실루엣)으로 한다.
- **구획선·잉크선이 진한 걸 싫어한다.** "벽·통나무 무늬 구분하는 선이 너무 진하다". 줄눈은 얇고 조용하게(판폭 1.7~2%, 같은 색의 어두운 값).
- **시스템 UI 는 웹툰 브론즈 바이브.** 먹판 + 청동 레일 + 당초문 + 낫표 「」.
- **화면 가리는 표시물은 연쇄적으로 제거돼 왔다**: 공격 쐐기 → 처치 전면 백색 번쩍 → 타수(「1타·2타」) → 기술명 카드 → 머리 위 느낌표. **새 표시물을 화면에 얹기 전에 이 목록을 먼저 보라.**
- **머리 위 바를 "말투째" 바꾸면 물린다.** 오너가 직접 되돌린 커밋이 있다(`7bec8db` → `46fdd9a`). 그때 물린 이유는 크기가 아니라 뱃지를 원형 메달로 바꾸고 바를 눈금 자로 갈아엎고 바코드 채움·피격 반응을 지운 것이었다.
- **서체는 오너가 직접 정했다**(Paperlogy, `86b5a2f`). 픽셀 서체를 다시 제안하지 마라.
- **장식 애니(Lottie·일러 모션)는 톤과 안 맞는다.** 기능적 모션만.
- **데모 스코프다.** 테스트·QA 는 최소한만.

## 7. 오너 판정 대기 — 전체 목록

`WORKQUEUE` 곳곳에 흩어져 있던 것을 한자리에 모았다. 굵은 것이 다음 세션에서 물어볼 값어치가 큰 항목이다.

### 전투 · 밸런스

1. **★보스를 잡몹과 같은 배율로 반감할지.** `boss.js` 는 자기 체력·피해를 따로 갖는 별도 체계다(MAX_HP 60 / Z 3 / X·C 5 = **20타·12타**). `enemy.js` 와 공유 상수가 0 이라 18차 반감이 보스에는 한 톨도 안 갔다. 반감하면 40타·24타 = 보스전 길이가 두 배.
2. **보스에 RPG 성장(기술배율·레벨배율)을 적용할지.** 지금은 잡몹에만 붙어 있다.
3. **★보스를 못 피한다.** 17차에 회피를 폐지했는데 `boss.js` 의 `tryLand` 가 **x·z 만 봐서 점프로는 어떤 패턴도 안 피해진다**(9/9 공중 피격). 회피가 메우던 구멍 둘이 지금 비었다 — ①칼 묶임 1.19초 중의 후려치기(예고 0.95s vs X 타격 0.94s) ②내려찍기 원(반경 3.6m) 한복판. 판정 축에 y 를 넣든, 회피를 되살리든(`DASH_ON=true`), 보스 패턴을 고치든 설계 결정이 필요하다.
4. **레벨 뱃지 상한.** 힘은 `LVL_CAP=12`(`enemy.js:365`)에서 멈추는데 UI 뱃지는 `1 + floor(kills/5)` 로 무한히 오른다(`ui.js:2695`). 뱃지도 멈출지.
5. 보스 데미지 숫자를 띄울지(12차부터 이월).
6. 잡몹 체력 분포(리더 3 / 일반 2·1). 데미지 반감으로 완화됐지만 분포 자체는 그대로다.

### 맵 · 구조

7. **★벽 금 71군데 근본 수리.** 17차는 못 들어가게 막았을 뿐 금은 그대로다. 뿌리는 `s40_dungeon1.py` 가 벽 줄을 앞벽·뒷벽 두 상자로 쪼갤 때 경계에서 **0.22m 씩 물러난 것**이고, 한 줄로 잇거나 칸 경계까지 붙이면 71 군데가 한 번에 사라진다.
8. 카메라 가림 168자리 중 **72 는 각을 최대로 세워도 안 열린다**(기둥에 0.95~1.14m 로 바짝 붙은 자리). 더 가려면 가리는 벽을 비치게 하는 길뿐이다(`level.js` 재질).
9. 각을 세우면 캐릭터 화면 세로가 10.91%→6.5% 로 짧아진다. "각이 도는 게 싫다"면 `CAM_LIFT_MAX = 0` 한 줄로 이 층만 꺼진다.
10. 따뜻 쐐기가 아직 0.487~0.636(롤 0.038~0.502). 손잡이는 `TORCH_RGB` 채도인데 내리면 15차 계약("밝은 띠 R/B 3 이상", 지금 2.80~3.46 으로 이미 하단)이 깨진다. **맞바꿈이라 판정이 필요하다.**
11. 메달리온 바깥 황동 띠가 아직 매끈하다 / 잔해가 한 벌 반복 / 모서리돌이 화면에서 은근하다(회수 가능 986KB) / 계단 앞 門만 콜라이더 밖(다리 사이 1.41m).
12. 웜 존이 웅덩이 여럿이다(컨셉은 홀 1/3 통짜 호박색) / 통로 한복판 어둠(p25 0.0024).
13. 절벽 짝 SEAT 정합 여부(12차부터 이월).
14. rock 채도 18.5% 로 맵 최저 / 근접에서 잎끝이 각진다(기본 거리에서는 무해).
15. 석탑이 어두워졌다(구판이 계약 위반이었다. 밝히려면 `M_STONE_PALE` hex) / 길 색이 레퍼런스는 황토인데 `K_PATH`("걸을 수 있는 곳 = 밝고 따뜻") 규칙과 충돌이라 보류 중.

### 모션

16. **Idle 칼각 취향.** 코드 기본은 `IDLE_E=78` · `IDLE_AZ=22` 다(문서 두 곳의 "70/35" 는 오기). 화면 칼 길이 비가 `|cos(E+40.7°)|` 라 **+45~50° 는 오히려 더 나쁘다** — 40% 계약을 만족하는 구간은 `E≤26` 또는 `E≥73` 둘뿐이다. 마음에 안 들면 `IDLE_GUARD=0`.
17. **X 커밋 +50ms**(`ATK_COMMIT.Heavy` 0.35→0.40). 18차 검도 X 가 길어져서 올렸다.
18. **X 는 옆으로 45° 눕힌 가파른 내려찍기다.** 순수 세로는 이 카메라에서 안 보인다 — 더 세로를 원하면 **카메라 pitch 를 낮추는 길뿐**이다.
19. Z 3타 장전에서 왼손이 1.1주먹 뜬다 / C 회수 리본 잔류.
20. 달리기 왼팔 과대(+72/−61) 미조치 / 달리기 보폭이 분당 116걸음이라 둥둥 뜬다(고치려면 추격 밸런스 재조정 필요).
21. Attack 런지에서 메시가 클립 바닥을 2.31% 통과한다(게임 접지가 흡수).
22. 베기 두 손 파지 유지 여부(`gw=0` 한 줄로 한 손 복귀).

### 이펙트

23. **일섬(`FX_V18=1`)이 최종인지.** `?fx=b` 로 귀멸 B 판, `?fx=a/c/d` 로 옛 대조군을 나란히 볼 수 있다.
24. (16차 이월, 대체로 일섬이 흡수) 봉인칼 리본이 무채색이라 **시작 칼을 백아로 바꿀지**는 여전히 게임 디자인 결정이다.

### UI · 표시

25. **상시 HUD 에 당초문을 확장할지.** 19차는 '시스템 창'에만 얹었다 — 전투 중 상시 띠에 장식을 두르면 눈이 거기 붙는다는 판단이었다.
26. 계기판 전폭(롤은 40.9% 가운데 정렬, 메이플이 100%) / 레벨 뱃지를 계기판 왼쪽에도 둔 것.
27. 층 돌파 축하 연출이 없다 / 클리어 패널 처치수가 `boss.js` 의 `clearInfo.kills` 0 고정이라 UI 가 화면만 덮고 있다.
28. **1번 칼 이름이 아직 「녹슨 칼」**(`main.js:3048`)인데 물건은 오너가 준 흑요석 대검이다.
