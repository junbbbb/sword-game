## ★건틀릿 루프 (2026-08-10 오너 지시, Matt Shumer 방식. 이후 모든 파도에 적용)
빌더가 만들고 끝이 아니다. **부문별 블라인드 비평가**가 실물 기준과 비교해 이길 때만 통과, 질 때마다 재작업. **전 부문 통과 전 배포 금지**(오너 승인 예외).
- 비평가는 **블라인드**: 빌더의 보고서·과정을 주지 않는다. 라이브 게임(headed)과 스크린샷, 그리고 실물 기준만 준다
- 부문과 실물 기준(합격선):
  1. 바닥·지형 ↔ **롤 소환사의 협곡** 같은 카메라 거리 비교. "밀리지 않는가"
  2. 칼 이펙트 ↔ **귀멸 애니 프레임**(레포 water-breathing 영상·webp). "한 장면을 캡처해 나란히 놓았을 때 같은 화풍으로 읽히는가"
  3. 전투 손맛 ↔ 상용 액션 기준 체크리스트(반응 지연·캔슬·타격 정지·판정 정직성) + 블라인드 플레이
  4. 캐릭터·모션 ↔ 롤 챔피언이 게임 거리에서 읽히는 수준(실루엣·자세·발 미끄러짐)
  5. 연출·UI ↔ 귀멸 타이틀 카드 + 롤 HUD 가독성
- 판정: 부문별 **PASS / FAIL + 격차 목록(심각도순)**. FAIL → 해당 부문 빌더 파도 → 그 부문만 재건틀릿
- 감독(메인/크론)은 빌더와 비평가를 짝지어 돌리고, 전 부문 PASS 에서만 배포한다
