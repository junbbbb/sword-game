### 멀티에서 밟은 함정 (전부 실측으로 잡았다)

1. **송신 주기를 `rawDt` 로 재면 안 된다.** 그 값은 `Math.min(0.05, delta)` 로 잘려 있어 **프레임이 낮을수록 실제보다 느리게 쌓인다** - 13.5fps 기계가 15Hz 를 시켰는데 6.75Hz 만 보냈다. 느릴수록 더 안 보내는 구조라 그 사람만 유독 끊겨 보인다. 벽시계로 재라
2. **데이터 채널을 `reliable` 로 열면 안 된다.** 유실 시 재전송 + 뒤 메시지가 줄을 선다(head-of-line blocking). 위치 스트림은 한 장 버리고 다음을 받는 쪽이 부드럽다. 대신 **순서가 뒤바뀌므로 받는 쪽이 옛 소식을 버려야 한다**(`msg.n`)
3. **TURN 이 하나도 없었다.** 크롬이 로컬 IP 를 mDNS 로 감춰서 **같은 공유기 안의 두 기기가 서로 못 붙는다**(헤어핀 NAT). 밖의 친구와는 붙는데 집 안에서는 안 붙는 그림. 공개 TURN(openrelay)을 넣었고 `경로 host/srflx/relay` 를 화면에 띄운다
4. **"바뀔 때 한 번 적어 두는" 방식은 자리를 빠뜨리면 조용히 틀린다.** 팀원 공격이 안 보인 원인 - 클립 이름을 `play()` 에만 적었는데 공격 셋은 play() 를 안 거치고 액션을 직접 조작한다(3연타는 클립 시간 점프). 지금은 **도는 액션에서 역산**한다
5. **화살 id 를 -1 부터 시작하면 첫 발이 아무도 못 맞춘다**(요괴가 `lastSwing:-1` 로 태어난다). -2 부터다
6. **두 창을 겹쳐 띄우면 뒤 창의 rAF 가 3fps 까지 떨어진다.** 멀티 검증은 `--window-position` 으로 겹치지 않게 띄워라

**착수 전 필독 순서**: `docs/HANDOFF.md` → 이 문서 §2·§5 → 건드릴 시스템의 `LOG.md` 절 → 해당 스크립트 헤더의 한국어 주석.

14. **A/B 는 라이브 `web/` 으로 찍으면 안 된다** — 병렬 에이전트가 그 사이 파일을 갈아서 무관한 차이가 시트에 섞인다. 미러 두 벌(js·html 은 사본, 나머지는 얼린 사본)을 세워라. 캔버스에 `preserveDrawingBuffer` 가 없어 rAF 밖에서 읽으면 빈 그림이 나온다. (LOG.md 절 제목: `### ★A/B 하네스 (다음 사람이 그대로 쓸 것 — fx_sheet/harness/)` — 실제 제목에서 경로는 백틱으로 감싸여 있다, L2439)
15. **`?dev` 로 시간·속도를 재지 마라 — 루프가 `setTimeout(16)` 이다** — 벽시계 기준 이동속도가 거짓이 되고, 계측 tick 의 rAF 가 4~10fps 로 떨어져 "950프레임"이 950 렌더프레임이 아니다. 같은 절: `web/basic2.glb` 는 이제 결과물이라 `s31` 에 다시 넣으면 칼 위에 칼을 꽂는다. (LOG.md: `### 함정 (다음 사람에게)` — `## 시작 캐릭터를 basic2 로 교체 (v100, 11차 파도)` 아래, L2336)
16. **프로브가 파이프라인이 지워 버리는 오브젝트를 재고 있었다** — `probe_hilt/drift/elbow` 가 전부 `katana_slayer` 를 쟀는데 `s6` 는 그걸 지우고 `SW_*` 를 굽는다. "이탈 0.002 합격" 판정이 통째로 무의미했다. **자는 항상 출고되는 물건을 겨눠야 한다.** (LOG.md: `### ★ 프로브가 잰 물건이 틀렸다`, L960)
17. **자기상관·스펙트럼으로 "모눈종이/타일 티"를 판정할 수 없다** — 같은 도장을 자리만 옮겨 찍은 것은 주기성이 없어 봉우리를 안 남기는데 눈은 바로 알아챈다(16·17차와 롤 레퍼런스가 1.41~1.94 로 구분 불가). 판을 키우면 자기상관은 그것만으로 내려간다. (LOG.md: `### ★★"모눈종이"는 자기상관으로 못 잡는다 (자를 하나 버렸다)`, L5499)
18. **"히트스톱이 없다"는 오진이었다 — 세계는 멎었고 카메라가 흘렀다** — `feel.js` 가 55/105ms 를 정확히 거는데 흔들림을 보간 **결과**에 더해서 다음 프레임 출발점이 오염됐다. 화소로 재면 멈춘 프레임이 오히려 342~400% 더 변한 프레임이 된다. **연출 진단은 게임 시계가 아니라 화소로.** (LOG.md: `### ★진단 — "히트스톱이 없다"는 오진이었다`, L5577)
19. **IK 팔에서 "얼마나 벌어졌나"를 목표값으로 판정하면 틀린다** — 손목을 26° 벌려 놓고도 실제 위팔은 7.6° 일 수 있다. 어깨→팔꿈치로 재고, 스위블 폴은 절대 방향 상수가 아니라 어깨→손목 축에 수직인 평면 안의 각으로 줘라. (LOG.md: `### ★함정 (다음 사람이 그대로 밟는다)` — `## 점프의 빈 팔은 팔꿈치가 갈비뼈에 붙어 있었다 (v99, 17차 파도)` 아래, L6379)
20. **한글 문장이 들어오는 판에 `display:flex` + `gap` 을 쓰지 마라** — flex 통의 글자는 연속 덩어리마다 익명 아이템으로 쪼개져 조사가 낱말에서 떨어진다(「제단의 증표 를 집어라」). gap 을 0 으로 줄이면 이번엔 앞뒤 공백까지 버려 붙는다. `inline-block` + absolute 라벨이 답이다. (LOG.md: `### ★「증표 를 집어라」의 진범은 조판이 아니라 **flex** 였다`, L5388)
